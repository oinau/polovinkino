# Тестирование

Три уровня: быстрые юнит-тесты, браузерные автотесты и визуальная проверка по чек-листу
(человеком или моделью с Playwright).

## 1. Юнит-тесты — `npm test` (Vitest, `tests/unit/`)

Проверяют данные и тексты, без браузера, за доли секунды:

- `fractions.test.ts` — дроби словами во всех падежах («одной третьей», «двух шестых»,
  «половины»), `simplify`, `compare`, `mul`.
- `levels.test.ts` — **каждый заказ решаем**: есть нарезка (заранее или из доступных кнопок),
  при которой ответ — целое число кусочков; для «X от Y» остаток делится поровну.
  Для гномов объяснение соответствует правильному ответу. Ловит ошибки при правке `levels.ts`.
- `phrases.test.ts` — в озвучиваемых фразах нет цифровых дробей («3/4» синтезатор читает как
  «три четыре»), ключи фраз уникальны и **стабильны** (смена хэша осиротила бы все записи
  студии), представления героев попадают в студию, формы заказов.

## 2. Браузерные тесты — `npm run test:e2e` (Playwright, `tests/e2e/`)

Сами поднимают Vite на порту 5199. Безголовый Chromium рисует канвас медленно (~20 кадров/с),
поэтому тесты управляют сценами через их методы (`window.__game`, только в dev-сборке)
и ждут состояния, а не кликают по таймингам.

- `smoke.spec.ts` — карта и каждый уровень каждой локации запускаются без ошибок в консоли.
- `pizzeria.spec.ts` — смены 1, 2, 3, 5 проходятся правильными ответами → 3 звезды;
  неверный ответ считается ошибкой и подсказка предлагает нужную нарезку;
  первый визит показывает карточку «Знакомься!» с Пыхом.
- `gnomes.spec.ts` — все три уровня проходятся честным судейством → 3 звезды; ошибка считается.
- `reset.spec.ts` — «Начать заново» обнуляет звёзды, монеты и знакомства, но не звук и голос.
- `voice.spec.ts` — запись играет вместо синтезатора, фраза без записи уходит в синтезатор;
  студия экспортирует zip с `manifest.json` и корректным WAV.

Первый раз нужен браузер: `npx playwright install chromium`.

## 3. Визуальная проверка по чек-листу

То, что автотесты не видят: вёрстка, читаемость, «понятно ли ребёнку». Проходить после
заметных изменений сцен — вручную или попросить модель с Playwright: открыть игру
(`npm run dev`), запустить сцену через `__game.scene.start('Pizzeria', { level: N })`,
делать скриншоты на каждом шаге и сверять с пунктами.

**Общее**
- [ ] Текст нигде не вылезает за пузыри, кнопки и плашки; ничего не перекрывается.
- [ ] Плашка-подсказка сверху всегда говорит, что делать сейчас; стрелка (где есть)
      указывает на нужный элемент.
- [ ] Неактивные кнопки заметно приглушены.
- [ ] Таблички с именами видны и не закрывают героев.

**Карта**
- [ ] Подписи зданий читаются, ни одна не обрезана краем экрана.
- [ ] «Голос: …» и «Начать заново» не мешают; сброс спрашивает подтверждение.

**Пиццерия** (каждая смена)
- [ ] Хвостик пузыря клиента указывает на голову говорящего; у Екибаса пузырь второй
      головы не налезает на основной.
- [ ] Выбранные кусочки заметно выдвигаются; «Взял: k/n» совпадает с картинкой.
- [ ] После ошибки: клиент злится, подсказка про нарезку или подсвеченные кусочки хорошо видны.
- [ ] Смена 5: на доске только часть пиццы, неподходящие кнопки нарезки неактивны,
      в пузыре «1/2 от 1/2».
- [ ] Карточка «Знакомься!»: портрет целиком, имя в одну строку, текст не налезает на кнопку.

**Гномы**
- [ ] Хвостики пузырей у колпаков; полоски пирогов выровнены по левому краю.
- [ ] После ответа подсвечена разница (или пунктир «поровну»), рядом дроби.

**Экран итогов**
- [ ] Пустые звёзды видны сразу, заполненные появляются по одной; кнопки не перекрываются.

**Звук** (вручную, с колонками)
- [ ] Заказы и объяснения произносятся словами («две третьих», а не «два три»).
- [ ] Записанные в студии фразы звучат вместо синтезатора.
