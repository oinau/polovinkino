Порядок мест на карте (по дороге): пиццерия → гномы → часы → пристань → доктор →
зельеварня → курьеры → дом монстров на горе (см. [map.md](../map.md)).

Сложность растёт так: доли (1/3, 1/6) → несколько долей (2/3, 5/6) → сравнение →
равные дроби → доля от числа → дроби больше единицы → сложение. Знаменатели 2, 3, 4, 6 — то, что проходят в 3-м классе.
