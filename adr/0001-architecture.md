# 0001 — Архитектура

Статус: принято · 2026-11

## Контекст

Браузерная 2D-игра про дроби для 3-го класса. Играет ребёнок на компьютере или планшете;
должна открываться по ссылке (позже — GitHub Pages), без сервера и установки.

## Решения

**Стек: Phaser 4 + TypeScript + Vite.** Phaser — полный 2D-фреймворк (сцены, ввод, твины, звук),
MIT. Альтернативы (PixiJS — только рендер, KAPLAY — для прототипов, Godot — тяжёлая веб-сборка)
отклонены. Сборка — статичный сайт в `dist/` (`base: './'`).

**Логическое разрешение 1920×1080, `Scale.EXPAND`.** Все координаты в коде — в этой сетке
(«сцена»). Холст занимает весь экран: если экран шире или выше 16:9, камера держит сцену
посередине (`src/stage.ts`), а по краям видно продолжение фона — фоны рисуются с запасом
`BLEED` за края сцены. Круглые кнопки прижаты к настоящим углам экрана, карта на широком
экране показывает больше города. Касания в сценах читаются в мировых координатах
(`pointer.worldX`), потому что камера сдвинута.

**Графика — SVG-строки в коде (`src/art.ts`).** Плоский стиль, 5 цветов (`src/theme.ts`),
без художника и файлов-ассетов. Каждое настроение персонажа — отдельная текстура
`<кто>-<настроение>` (`normal / happy / angry`, у Пыха — `worried`). При загрузке SVG
кодируются в base64 data-URI (загрузчик Phaser понимает только base64) и растеризуются
с нужным `scale`. Пицца, пироги, кнопки, пузыри рисуются через `Graphics`.

**Уровни — данные (`src/levels.ts`).** Заказы, нарезка, терпение, споры гномов описаны
объектами; сцены их только исполняют. Новый уровень той же локации — правка данных.

**Сцены (`src/scenes/`).** `Boot` (загрузка) → `Town` (карта, выбор уровня) →
`Pizzeria` / `Gnomes`. Общий UI — в `src/ui.ts`: `Button`, `Bubble`, `FractionView`
(дробь «в столбик»), `Guide` (подсказка + стрелка), модальные окна и экран итогов.

**Дроби словами (`src/fractions.ts`).** `words(frac, 'nom' | 'acc' | 'gen')` по-школьному:
«одна третья / одну третью / одной третьей», «две третьих», «половина». На экране дробь
всегда цифрами, вслух — словами (TTS читает «3/4» как «три четыре»).

**Звук (`src/audio.ts`).** Эффекты синтезируются WebAudio (файлов нет). Речь: если у фразы
есть своя запись — играет она, иначе браузерный `speechSynthesis` (русские голоса ранжируются:
естественные и RHVoice выше, eSpeak последним; на карте есть выбор голоса). Сбой речи никогда
не ломает игру.

**Свои записи голосов.** Все реплики живут в `src/lines.ts`; `src/phrases.ts` строит из уровней
полный список озвучиваемых фраз. Запись ищется по хэшу текста фразы (`src/voicekey.ts`,
FNV-1a от нормализованного текста), поэтому код сцен не знает о записях: `speak(text)` сам
решает, что играть. Записи делаются в студии (`studio.html`, `src/studio/`): MediaRecorder →
обрезка тишины и нормализация → IndexedDB; тон персонажа — `playbackRate` при рендере
в `OfflineAudioContext` (тон и скорость вместе); экспорт — zip с WAV 24 кГц и
`public/voice/manifest.json`. Если текст фразы поменялся, старая запись просто перестаёт
находиться, и фраза снова звучит синтезатором. Публичная сборка без записей —
`npm run build:public`.

**Прогресс — `localStorage`** (`src/store.ts`, ключ `polovinkino.v1`): звёзды по уровням,
монеты, звук, выбранный голос. Привязан к браузеру и адресу сайта.

## Принципы для ребёнка

- **Одна точка внимания.** Тёмная плашка сверху всегда говорит, что делать сейчас; на первых
  уровнях — прыгающая стрелка. Неактивные действия приглушены.
- **Ошибка — не game over.** Персонаж реагирует, игра показывает, что ребёнок дал
  («2/6 — то же, что 1/3»), подсвечивает правильный ответ и даёт попробовать снова.
- **Три вида дроби сразу:** словами, цифрами, картинкой.
- **Герои с именами.** У каждого табличка с именем; при первой встрече — карточка
  «Знакомься!» с портретом и парой фраз о герое (озвучивается, показывается один раз;
  кто уже знаком — в `localStorage`). Тексты — `HEROES` в `src/lines.ts`.
- **Задания озвучены**, чтобы проверялись дроби, а не скорость чтения.
- **Звёзды — по числу ошибок** (0 → 3, 1–2 → 2, больше → 1). Следующий уровень открывается
  при любой звезде.

## Разработка и проверка

- В dev-сборке игра доступна как `window.__game` — удобно запускать сцену напрямую
  (`__game.scene.start('Pizzeria', { level: 2 })`) и проверять Playwright-скриптами.
- `npm run build` = `tsc --noEmit` + сборка Vite.

## Последствия

- Нет ассетов → быстро меняем персонажей, но сложная анимация (скелетная) не предусмотрена.
- Качество голоса зависит от устройства. Если станет важным — заранее записать фразы
  нейросетевым TTS (например, Piper) и проигрывать файлы.
- Прогресс не переносится между устройствами (возможное решение — экспорт/импорт кодом).
