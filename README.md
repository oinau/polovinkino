# Половинкино

Браузерная игра про дроби для 3-го класса (Phaser 4 + TypeScript + Vite).

- **Пиццерия «Кусочек»** — 5 смен: отдать нужную долю пиццы, самому нарезать, равные дроби (4/6 = 2/3), час пик с терпением клиентов, дробь от дроби («половина от половины»).
- **Беседка спорщиков** — 3 уровня: сравнить доли двух гномов (с картинкой, только по числам, «поровну»).
- **Площадь с часами** — 3 уровня: носок Тихон ждёт Носочку. Который час по стрелкам, поставить стрелки, сколько минут ждать (четверть часа = 1/4 часа).
- **Пристань** — 3 уровня: капитан Сардина делит клад. Разложить монеты в равные кучки и отдать нужные (2/3 от 12), потом в уме и обратная задача («треть — 4 монеты, сколько всего?»).
- **Мост бобра Бруно** — 4 уровня: закрыть дыру в мосту досками 1/2, 1/3, 1/4, 1/6 ровно, без щелей (1/2 + 1/4 + 1/4 = 1).
- **Кабинет доктора** — 4 уровня: доктор Цапля меряет рост в «домиках». Поставить планку ростомера (Боровик — 1/4 домика), назвать рост, жираф Жорж не влезает (5/4 = 1 1/4), расставить всех по росту.
- **Зельеварня** — 4 уровня: совёнок Пип варит зелья. Налить ингредиенты по рецепту в колбу с делениями и сказать, сколько получилось (1/4 + 2/4 = 3/4, а не 3/8), полная колба, сколько долить.
- **Курьеры** — 4 уровня: ёжик Шустрик на самокате везёт пиццу в дом на 3/4 улицы. Улица — числовая прямая: четверти, шестые, на глаз, длинная улица до 2 (5/4).
- **Дом монстров** (на горе в конце дороги) — 5 комнат: торт на 8 кусков, порванная паутина, свечи на сквозняке, малыш-слизень перерос дверь, часы с летучей мышью. После последней комнаты — «Диплом мастера дробей» (каждый раз).

Карта города — длинная улица с прокруткой (пальцем, колёсиком или стрелками): места идут
по дороге, а в конце на горе виден дом монстров.

Архитектура и описание уровней (готовых и планируемых) — в [`adr/`](adr/README.md).

## Запуск

Нужен Node.js 20.19+ или 22.12+ (требование Vite).

```sh
npm install
npm run dev        # http://localhost:5173
npm run build          # проверка типов + статичный сайт в dist/
npm run build:public   # то же, но без записанных голосов (dist/voice удаляется)
npm run preview        # посмотреть собранный dist/
```

### Тесты

```sh
npm test                          # юнит-тесты (Vitest), доли секунды
npx playwright install chromium   # один раз, браузер для автотестов
npm run test:e2e                  # браузерные тесты (Playwright), пару минут
```

Браузерные тесты сами запускают Vite на порту **5199** (не мешает `npm run dev` на 5173);
если порт занят чужим процессом, освободите его.

Один файл или один тест:

```sh
npx vitest run tests/unit/levels.test.ts      # один файл юнит-тестов
npx vitest run -t "words"                     # тесты, в названии которых есть «words»
npx playwright test tests/e2e/gnomes.spec.ts  # один файл браузерных тестов
npx playwright test -g "shift 5"              # браузерные тесты по части названия
```

Что именно проверяется и чек-лист визуальной проверки — в [`adr/testing.md`](adr/testing.md).

### Сбросить прогресс

Прогресс хранится в `localStorage` браузера (ключ `polovinkino.v1`), отдельно для каждого
адреса сайта. Сброс — **«Начать заново»** в настройках (шестерёнка на карте; обнуляет звёзды, монеты и знакомства
с героями; звук и выбранный голос остаются) или в консоли браузера:
`localStorage.removeItem('polovinkino.v1')`.

## Студия озвучки (свои голоса)

Фразы можно озвучить самим — например, вместе с детьми. Откройте `studio.html`
(`http://localhost:5173/studio.html`; микрофон работает только на localhost или по HTTPS):

- слева — все фразы игры (список строится из уровней сам), фильтр по персонажам
  и «только незаписанные»;
- **Пробел** — запись / стоп, **Enter** — послушать, **← →** — соседние фразы;
  тишина в начале и в конце обрезается, громкость выравнивается;
- ползунок «Голос персонажа» делает голос ниже и медленнее (Дед Боровик) или выше и быстрее
  (гномы) — тон и скорость меняются вместе, как в мультфильмах; настройка общая для персонажа;
- записи хранятся в браузере, пока их не скачать; **«Скачать всё (zip)»** — полный набор:
  распакуйте zip в корень проекта, файлы лягут в `public/voice/` (`manifest.json`, WAV-файлы
  и `index.tsv` со списком «файл — кто — текст»).

Игра сама проигрывает записи, а для фраз без записи говорит синтезатор.
Одна фраза — около 50 КБ на секунду звука (WAV, 24 кГц).

**Приватность.** GitHub Pages публикует сайт открыто. Если голоса детей не должны попасть
в интернет, собирайте публичную версию командой `npm run build:public` — записи в неё
не попадут. Изменение тона в студии не защищает: его легко отменить, а знакомые узнают голос.
Если записи не нужны и в git, добавьте `public/voice/` в `.gitignore`.

## Голос

Задания читает встроенный в браузер синтезатор речи (`speechSynthesis`). Игра сама выбирает
лучший русский голос, а в настройках на карте (шестерёнка) есть «Голос: …» — каждое нажатие переключает голос
и даёт его послушать, и «Ударения: …» — как отмечать ударение для этого голоса. Если русских
голосов нет, этих строк нет и игра молчит (звуковые эффекты остаются).

В правом верхнем углу карты три кнопки: шестерёнка (настройки), полный экран (только там, где
браузер его умеет; на iPhone Safari разрешает его лишь видео) и звук — он вне меню, чтобы
выключать его сразу.

Звук в браузере включается только после первого нажатия на странице — это нормально.

### Проверить произношение

Синтезатор получает текст через словарь `src/pronounce/dictionary.ts`; на экране и в ключах
записей студии остаётся обычное написание:

- некоторые слова всегда переписываются «как слышится»: «пицца» → «пица»;
- ударения (Ца́пля, Екиба́с, Боровика́…) по умолчанию не ставятся: голоса на разных устройствах
  понимают их по-разному.

Страница `pronounce.html` (`http://localhost:5173/pronounce.html`) — все слова словаря и фразы
игры в вариантах: как написано, переписанные, со знаком ударения (U+0301) и с ударной гласной
заглавной буквой. Послушайте на устройстве, где играет ребёнок, и там же выберите, как ставить
ударения в игре **на этом устройстве** (настройка хранится в браузере вместе с прогрессом).
Новое слово — строчка в `STRESSED` с апострофом после ударной гласной: `"Ца'пля"`.

### Linux (Firefox, в том числе snap)

Firefox говорит через speech-dispatcher, а там по умолчанию eSpeak — очень роботизированный.
Намного лучше звучит RHVoice (голоса Anna, Elena, Irina, Aleksandr-hq и др.):

```sh
sudo apt install rhvoice rhvoice-russian speech-dispatcher-rhvoice
pkill -f speech-dispatcher           # перезапустить, чтобы подхватил модуль
spd-say -O                           # в списке должен быть rhvoice
spd-say -o rhvoice -l ru "Мне две третьих пиццы"
```

Потом полностью перезапустить Firefox. Проверить, что браузер видит голоса (в консоли):

```js
speechSynthesis.getVoices().filter(v => v.lang.startsWith('ru')).map(v => v.name).filter(n => !n.includes('+'))
```

Проверено на Ubuntu с Firefox из snap: голоса RHVoice появляются.

### Linux (Chrome / Chromium)

Тоже используют speech-dispatcher, так что RHVoice из пункта выше подходит. Если голосов
нет совсем, попробуйте запустить браузер с флагом `--enable-speech-dispatcher`.

### Windows

- **Edge** — лучший вариант: есть онлайн-голоса Microsoft «Natural» (например, Svetlana, Dmitry),
  игра выберет их сама.
- **Chrome / Firefox** — используют голоса Windows. Если русского нет: Параметры → Время и язык →
  Речь → «Добавить голоса» → Русский (голос Irina), затем перезапустить браузер.

### macOS и iOS

Есть системные голоса Milena и Yuri. Лучше скачать улучшенную версию:
- macOS: Системные настройки → Универсальный доступ → Устной контент → Системный голос →
  Управлять голосами → Русский → Milena (улучшенный).
- iPhone / iPad: Настройки → Универсальный доступ → Устной контент → Голоса → Русский.

### Android

Chrome использует «Синтез речи Google»: Настройки → Система → Язык и ввод → Синтез речи →
Google → установить русский голос.

## Где что лежит

- `src/levels.ts` — все уровни и заказы: менять сложность здесь.
- `src/art.ts` — персонажи и здания (SVG в коде, у каждого настроения `normal / happy / angry`).
- `src/fractions.ts` — дроби словами («две третьих», «одну шестую», «одной третьей»).
- `src/lines.ts` — все реплики персонажей; `src/phrases.ts` — список всех озвучиваемых фраз для студии.
- `src/audio.ts` — звуковые эффекты, выбор голоса, проигрывание записей.
- `studio.html`, `src/studio/` — студия озвучки; записи — в `public/voice/`.
- `pronounce.html`, `src/pronounce/` — проверка произношения синтезатором на разных устройствах.
- `src/time.ts` — время словами («половина третьего», «без четверти три»).
- `src/map.ts` — раскладка карты: где стоят места, ширина мира, какое место следующее.
- `src/scenes/` — карта города, пиццерия, гномы, часы, пристань, мост бобра, доктор, зельеварня, курьеры, дом монстров.
- `adr/` — архитектура и уровни.
- `mockup/style.html` — первый макет стиля.
