# Половинкино

Браузерная игра про дроби для 3-го класса (Phaser 4 + TypeScript + Vite).

- **Пиццерия «Кусочек»** — 4 смены: отдать нужную долю пиццы, самому нарезать, равные дроби (4/6 = 2/3), час пик с терпением клиентов.
- **Беседка спорщиков** — 3 уровня: сравнить доли двух гномов (с картинкой, только по числам, «поровну»).

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # статичный сайт в dist/, открывается с любого хостинга
```

## Где что лежит

- `src/levels.ts` — все уровни и заказы: менять сложность здесь.
- `src/art.ts` — персонажи и здания (SVG в коде, у каждого настроения `normal / happy / angry`).
- `src/fractions.ts` — дроби словами («две третьих», «одну шестую»).
- `src/scenes/` — карта города, пиццерия, гномы.
- Прогресс (звёзды, монеты, звук) хранится в `localStorage` браузера.
- `mockup/style.html` — первый макет стиля.
